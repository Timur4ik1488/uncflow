# Fleet Hub (Stress-Test Repository)

Синтетический Kotlin / Spring Boot / Gradle Kotlin DSL проект для стресс-тестирования самописных сканеров безопасности (SECRET, SCA, SAST).
Все учётные данные, ключи, токены и записи базы данных являются полностью вымышленными.

Fleet Hub управляет автопарком, диспетчерскими заявками, тарифами и счетами.

Пример настройки интеграции в документации (НЕ уязвимость, контрольный пример):
`apiKey = "YOUR_API_KEY"` и `password = "CHANGEME"`.

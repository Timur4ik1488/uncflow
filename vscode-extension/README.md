# uncflow Security Audit (VS Code Extension)

Интеграция платформы комплексного аудита безопасности **uncflow** прямо в VS Code!

Больше не нужно переключаться между редактором и браузером: запускайте аудит проекта в один клик, просматривайте подсвеченные уязвимости в коде, изучайте рекомендации AI-аналитика (GigaChat) и применяйте безопасные исправления по лампочке (`Ctrl+.`).

Расширение по умолчанию настроено на работу с сервером **`https://uncflow.duckdns.org`**.

---

## ✨ Возможности

1. **Кнопка в заголовке редактора (Editor Title Bar)**:
   - `▶ Запуск`: мгновенный прогон текущего открытого проекта по выбранному сценарию.
   - `📋 Сценарии`: быстрое меню (QuickPick) для выбора сценария из каталога шаблонов uncflow (Комплексный аудит, Быстрый поиск утечек секретов, SAST аудит, Проверка зависимостей SCA).
2. **Интерактивный статус-бар (Status Bar)**:
   - Отображает текущий сценарий и статус запуска.
   - Во время работы: анимированный индикатор `$(sync~spin) uncflow: сканирование...`.
   - По завершении: бейдж `$(shield) 2 Critical | 4 High` с подсветкой.
3. **Нативная подсветка проблем (Problems / Squiggles)**:
   - Красные и жёлтые волнистые линии прямо на строках с уязвимостями.
   - Всплывающие подсказки (Hovers) с детальным объяснением риска и рекомендацией.
   - Группировка во вкладке **Problems** (`Ctrl+Shift+M`).
4. **Быстрые исправления (Quick Fix / Лампочка `Ctrl+.`)**:
   - Автоматическая замена захардкоженных паролей/токенов на переменные окружения `System.getenv(...)`.
   - Обновление версий уязвимых библиотек в `build.gradle.kts`.
   - Отключение небезопасных настроек (например, `allowCredentials(true)` при wildcard origin).
5. **Боковая панель (Activity Bar)**:
   - Вкладка **"Найденные уязвимости"**: дерево находок по категориям (Секреты, SCA-зависимости, SAST).
   - Вкладка **"AI Экспертиза и Рекомендации"**: карточка анализа с подробным описанием сценария атаки и планом remediation.
6. **Работа с удалённым и локальным сервером uncflow**:
   - По умолчанию подключен к **`https://uncflow.duckdns.org`**.
   - Автоматическая безопасная упаковка проекта в ZIP-архив на лету (с фильтрацией служебных директорий `.git`, `node_modules`, `build`, `.gradle`).
   - При работе с локальным бэкендом (`localhost:3001`) передаёт путь напрямую без лишнего копирования.

## 🚀 Быстрый старт

### Установка готового пакета (.vsix)

```bash
code --install-extension uncflow-security-1.0.0.vsix
```

Либо в VS Code:
1. Перейдите во вкладку **Extensions** (`Ctrl+Shift+X`).
2. Нажмите меню `...` (Views and More Actions) сверху справа.
3. Выберите **Install from VSIX...** и укажите файл `uncflow-security-1.0.0.vsix`.

---

## 🛠️ Сборка из исходников

```bash
cd vscode-extension
npm install
npm run build
npm run package
```

После выполнения команды в папке появится файл `uncflow-security-1.0.0.vsix`.

---

## ⚙️ Настройки расширения

- `uncflow.serverUrl`: URL платформы uncflow (по умолчанию `https://uncflow.duckdns.org`).
- `uncflow.defaultWorkflowId`: ID сценария аудита по умолчанию (по умолчанию `template-full-audit`).
- `uncflow.apiToken`: Токен авторизации (если на бэкенде включена авторизация по `CI_API_TOKEN`).
- `uncflow.runOnSave`: Автоматически запускать аудит при сохранении файлов (`false` по умолчанию).
- При подключении к удаленному серверу проект автоматически упаковывается в ZIP-архив перед загрузкой.
